# benandersonbooks

Author site for Ben Anderson, starting with *Ash of Verdance*, a clean gaslamp fantasy mystery (November 17, 2026).

## Layout

- `site/` is the static website (plain HTML, no build step). Vercel deploys it with **Root Directory** set to `site`.

More to come: the AI-assisted novel-writing system used to make the book will be added here so others can reuse it.
